# endor

Today-first personal productivity starter built with Vue 3, Vite, and Supabase.

## Setup

1. Put your Supabase project URL and anon key in `.env.local`.
2. Apply the schema in [supabase/migrations/20260509000000_initial_schema.sql](supabase/migrations/20260509000000_initial_schema.sql).
3. Run the app with `npm run dev -- --host` from this folder.
